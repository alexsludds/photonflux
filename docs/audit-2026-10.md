## Physics and model findings not fixed here

These are ranked by how far they move results. Each one needs a design decision or touches many models.

1. **Two envelope sign conventions coexist.**
   - *Physics* `e^{-iωt}`, where envelope `+f` sits at optical `f0−f`: `cx.cw_laser`'s WDM offset, every CMT ring (`ring_mod.va` and its parts, `ring_filter`, `ring_nl`, `ring_kerr`, `ring_selfheat`, `ring_mod_inj`, the `cx` ring components), the EDFA gain-peak offset, `opt_filter`, and the optical-spectrum display.
   - *Engineering* `e^{+jωt}`: `fiber_cd`, `fiber_nl`, `ssfm.py`, the coherent CD filter, `waveguide_nl.va` (Kerr is a phase lag), and circulax's `OpticalWaveguide`, `pn_phase_shifter` and the TW part (`e^{−jφ}` together with a Padé delay `e^{−jΩτ}`).

   The consequences:
   - WDM walk-off through fibre has the wrong sign. A blue channel, which sits at Ω < 0, gets group delay β₂ΩL > 0 on positive-D fibre, so it arrives *late*.
   - Chirp × dispersion has the wrong sign for chirped transmitters (rings, phase shifters, the IQ modulator) driving `fiber_cd` or `fiber_nl`.
   - In a WDM transient, a ring built from `transit = delayed` waveguides sees each laser mirrored about the reference frame.

   Chirp-free single-carrier intensity is unaffected, which is why no test caught this.

   **Fix:** adopt circulax's engineering convention everywhere. That means flipping the `cw_laser` offset sign, the CMT `+jδ`, the EDFA `w_pk`, the `opt_filter` offset and the spectrum mapping. Then add a convention test: a two-tone WDM bus through `fiber_cd`, plus a delayed-waveguide ring, must agree with a DC wavelength sweep.

2. **The NRZ TDEC reference receiver bandwidth is probably too wide.**
   - `tdec.measure` uses 0.75 × baud as its default. `optimize.TDEC_DEFAULTS` and the Eye tab follow it.
   - 802.3 clause 95.8.5 TDEC uses a fourth-order Bessel-Thomson at **12.6 GHz** for 25.78 GBd, about 0.49 × baud.
   - 19.34 GHz (0.75 × baud) is the eye-mask / SEC receiver.
   - A wider receiver filters less ISI, so the simulated TDEC is optimistic.
   - Check the exact clause for the lane rates in use before changing the default. The value comes from a working-group contribution quoting the clause ([IEEE 802.3db, Zivny 2021](https://grouper.ieee.org/groups/802/3/db/public/November-08-November-17-2021/zivny_3db_01_111121.pdf)); the 19.34 GHz figure is from [King, 802.3cd 2017](https://www.ieee802.org/3/cd/public/July17/king_3cd_01a_0717.pdf).

3. **Traveling-wave laser slices use a first-order upwind lag, not a delay.**
   - `tw_seg.va` and `tw_gain_seg.va` propagate with `τ_s·dR/dt + R = R_left`. That stage is a low-pass with \|H\|² = 1/(1+(ωτ_s)²).
   - At the default dz = 10 µm, a mode 100 GHz from the frame loses about 0.026 dB per slice per pass.
   - The result is a spurious gain filter centred on `lambda_nm` that biases mode competition and SMSR in the DFB, DBR and FP examples.
   - **Fix:** use the Padé(1,1) all-pass that `catalog._transit_stage` already implements, which has exact magnitude.

4. **The ring modulator's junction is linear.**
   - `ring_phase_shifter.va` (and therefore `ring_mod.va`) and `cx.ring_phase_shifter` use a constant `dl_dv_pm` and a constant `cj`.
   - The newer `pn_phase_shifter` already has the abrupt-junction law: Δn ∝ √(1+V/V_bi) − 1 and C_j ∝ 1/√(1+V/V_bi).
   - `docs/stateye-integration-plan.md` §4.3 notes that the MRM (W, L) optimum is biased until this changes.

5. **The default PRBS jitter is large.**
   - RJ, SJ and DJ each default to 0.05 UI, which gives a TJ at 1e-12 of about 0.85 UI.
   - 18 of the 20 example PRBS sources inherit at least one of these defaults: examples 10–14, 17–19, 43 and 45–47.
   - **Fix:** default to 0 for a clean pattern, or about 0.01 UI rms for a realistic transmitter.

6. **The EDFA's spectral shape is decoupled from saturation.** The Lorentzian is applied after a wavelength-blind saturation, so gain tilt never changes with load or inversion. This is fine as a toy, but it should be documented.

7. **The Raman `g_r` default (0.6e-13 m/W) is the co-polarized peak.** A standard, polarization-scrambled span sees about half of it (C_R ≈ 0.35–0.4 /W/km). Counter-pumping is also treated as co-pumping, which is exact only when the pump is undepleted.

8. **The silicon nonlinear defaults are 1550 nm numbers used at the 1310 nm default wavelength.**
   - σ_FCA and dn/dN scale as λ².
   - `ring_selfheat`'s 80 pm/K corresponds to about 61 pm/K at 1310 nm with n_g = 4.

9. **There are two PRBS LFSRs.** `photonflux.signals.prbs` and `webapp/wavesrc.prbs_bits` produce the same sequences but start at different phases. Pick one and import it.

## Structural recommendations

1. **CI runs no tests.** The workflows build openvaf-ir, the image and the demo site. Add a pytest job that runs inside the built image and split the suite with a `slow` marker. SKY130 card extraction dominates a cold run.
2. **AC and small-signal noise analyses have zero tests.** This branch verified its AC refactor by bit-comparing examples 06, 24 and 42. Turn that comparison into a regression test.
3. **Split `webapp/catalog.py` (3.3k lines).**
   - It mixes catalog data, about 1.2k lines of JAX components and user-VA registration.
   - About 20 VA entries repeat the same field↔(re, im) adapter "expand" boilerplate, roughly 400 lines that one helper could generate.
   - This was not done here because the two open worktree branches (`cleanup/bump-circulax-bosdi`, `feature/cmr-true-delay`) also touch the file.
4. **Move the reusable components into the library.**
   - The photodiode, APD, TIA, CTLE, transit stages and LTI blocks live only in `webapp/catalog.py`.
   - The examples carry a second photodiode (`examples/photodiode_tia.Photodiode`), which `link_cmos.py` and `link_sky130.py` import from another example script.
   - Move these into `photonflux` (for example `photonflux/components.py`).
5. **Make `webapp` a package.** Its modules are reached by `sys.path.insert` hacks: 20 test modules, `cli.py`, `warmup.py` and `tools/` (`sys.path.insert` appears in 28 tracked files in all).
6. **Consolidate duplicated helpers.**
   - Three NaN→None JSON sanitizers: `server._finite`, `cli._finite` and `eyemeasure._num`.
   - Two TDECQ "outer, else xp" pickers: `linkpost` and `eyemeasure`.
   - The progress, cancel and error plumbing duplicated between `nb.Session.run` and `nb.Session.flow`.
7. **Harden the public deployment.**
   - `/api/upload` is ungated: 20 MB per file, unbounded count, so it can fill the disk.
   - `/api/eyemeasure` takes no lock and has no time limit, so it can saturate the CPU.
   - Gate both the way `PHOTONFLUX_ALLOW_VA_UPLOAD` gates VA upload.
8. **Fix the caches.**
   - The lowering cache key reads `bosdi.__version__`, which does not exist. This is already fixed on `cleanup/bump-circulax-bosdi`.
   - `cx.attenuator()` and `cx.terminator()` build a new class per call, unlike the other `cx` components.
   - `build_models` re-creates every built-in component class on each models-cache miss.
9. **Clean up the docs and tooling.**
   - `CLAUDE.md` asks for `bun run build`, but there is no JS build. Use `node --check` plus pytest.
   - `docs/stateye-integration-plan.md` (725 lines) is mostly done; trim it to the open items.
   - The Dockerfile still pins circulax 0.2.1 / bosdi 0.1.5 (the bump branch is pending).
   - In `models/util`, the module in `capacitor.va` is named `cap`, which breaks the documented rule that the module name equals the file stem.
